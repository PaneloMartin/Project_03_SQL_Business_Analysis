# Project 03 - SQL Business Analysis

## Goal

Develop a business-oriented SQL project using a relational database to answer real business questions.

---

## Database

Northwind (SQLite)

---

## Main Objective

Use SQL to transform transactional data into actionable business insights.

---

## Planned Business Questions

### Sales

- Total revenue
- Monthly sales trends
- Best month by revenue

### Customers

- Top customers
- Revenue by country
- Average order value

### Products

- Best selling products
- Most profitable categories

### Employees

- Employee performance

### Advanced SQL

- CTEs
- Window Functions
- Rankings
- Running Totals
